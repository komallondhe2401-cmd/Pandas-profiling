# 📊 Pandas Profiling on Train Dataset 

## 📌 Project Overview

This project demonstrates the use of **Pandas Profiling** to perform **automated Exploratory Data Analysis (EDA)** on the `train.csv` dataset from Kaggle. The profiling report provides a detailed summary of the dataset, helping to quickly understand its structure, quality, and patterns.

---

## 🎯 Objectives

* To analyze the `train.csv` dataset efficiently
* To detect missing values, outliers, and correlations
* To generate a complete EDA report in a single step

---

## 🛠️ Tools & Libraries Used

* Python 🐍
* Pandas
* ydata-profiling (Pandas Profiling)

---

## 📂 Dataset

* Dataset Name: `train.csv`
* Source: Kaggle
* Description: Dataset used for data analysis and preprocessing (e.g., contains features like age, category, etc.)

---

## ⚙️ What is Pandas Profiling?

Pandas Profiling is a Python library that generates a **detailed and interactive EDA report** automatically, including statistics, distributions, correlations, and data quality checks.

---

## 📊 Features of the Report

* 📌 **Overview**: Number of rows, columns, missing values
* 📈 **Variable Summary**: Data types, unique values, distributions
* ⚠️ **Alerts**: Missing data, high correlation, skewness
* 🔗 **Correlation Matrix**: Relationship between features
* 📉 **Missing Value Analysis**
* 📦 **Sample Data Preview**

---

## 🔍 Key Insights

* Identified missing values in important columns
* Detected highly correlated features
* Observed skewness in numerical variables
* Found potential outliers

---

## 📈 Output

* Generated an interactive HTML report: `output(1).html`
* Can be opened in any web browser
